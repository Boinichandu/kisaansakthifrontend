# 🌾 Kisan Sakthi - Frontend

Kisan Sakthi is a smart agriculture web application developed to help farmers make better farming decisions using modern technology. The application provides weather updates, market prices, farming tips, government subsidies, crop disease detection, and expert guidance through a simple and user-friendly interface.

---

## 🚀 Features

- 👤 User Registration & Login
- 🏠 Farmer Dashboard
- 🌦 Live Weather Information
- 💰 Market Price Information
- 🌱 Government Subsidies
- 📖 Farming Tips
- 🤖 AI Crop Disease Detection
- 👨‍🌾 Expert Consultation
- 👤 User Profile
- 🔔 Notifications
- 📜 Scan History
